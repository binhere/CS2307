Chức năng của trang web

Thuật ngữ và ký hiệu

BĐS
bất động sản; mỗi tin đăng bán ứng với một BĐS.
API
điểm giao tiếp mà một chương trình gọi tới qua HTTP, ví dụ GET /v1/properties.
Proxy Next.js
route app/api/* của frontend chuyển tiếp request sang backend; trình duyệt không gọi thẳng backend.
FastAPI
framework Python của backend.
threadpool
nhóm luồng phụ chạy các tác vụ blocking (truy vấn cơ sở dữ liệu, bcrypt, model) để event loop, vòng lặp nhận request của server, không bị treo.
PostgreSQL · pgvector
cơ sở dữ liệu quan hệ chứa tin đăng, tài khoản, hội thoại; pgvector là extension tính khoảng cách giữa các embedding.
Embedding
vector 1024 chiều biểu diễn nghĩa của một đoạn văn; hai đoạn gần nghĩa có vector gần nhau.
Neo4j · Cypher
cơ sở dữ liệu graph lưu node (tin, phường, đường, tiện ích) và các cạnh nối chúng; Cypher là ngôn ngữ truy vấn của Neo4j.
MinIO
kho lưu file theo chuẩn S3 (chuẩn lưu trữ file của Amazon), chứa ảnh tin đăng.
LLM
mô hình ngôn ngữ lớn, gọi qua API (Gemini hoặc API tương thích OpenAI).
LangGraph
thư viện ghép các bước gọi LLM và tool thành một graph rẽ nhánh theo điều kiện.
JWT
token có chữ ký số (thuật toán HS256), chứng minh request đến từ người đã đăng nhập.
bcrypt
hàm băm mật khẩu cố ý chậm, để việc dò mật khẩu tốn nhiều thời gian.
R²
tỷ lệ phương sai của giá mà model giải thích được, từ 0 đến 1; càng gần 1 càng tốt.

Màu ô: xanh lá = trình duyệt (Next.js) · tím = backend (FastAPI) · cam = nơi lưu dữ liệu · trắng viền liền = đầu vào hoặc kết quả · trắng viền nét đứt = dịch vụ bên ngoài hoặc bước offline · khung xám = nhóm theo tầng · ⚠ = hạn chế đã kiểm chứng trong code hoặc khi chạy thử.

1. Tìm nhà theo bộ lọc

Trang chủ lọc và sắp xếp tin bằng SQL thuần: không gọi AI, không dùng Neo4j.

2. Xem chi tiết tin

Mỗi phần của trang tự gọi API riêng, chạy song song nên phần chậm không chặn phần khác.

3. Định giá AI

So giá rao của tin với giá ước tính của model; tin nằm ngoài vùng dữ liệu huấn luyện thì không định giá.

  • Tư vấn AI cũng dùng định giá này khi người dùng hỏi về một tin đã được gợi ý.

4. Bất động sản tương tự

Tìm tin giống tin đang xem bằng hai tín hiệu: nghĩa của nội dung (vector) và vị trí, tiện ích chung (graph).

5. Bản đồ liên kết khu vực

Vẽ graph của một tin: phường, đường, khu vực hành chính cũ và các tiện ích lân cận.

6. Tư vấn AI

Chat nhiều lượt: một LLM phân loại câu hỏi, câu cần tư vấn thì gọi tool tìm kiếm rồi viết câu trả lời từ kết quả.

  • Mọi node có “(LLM)” gọi LLM API ở cột phải.
  • Một lượt tư vấn gọi LLM 4 lần nối tiếp: supervisor, consultant, bước LLM viết lý do bên trong hybrid search, và advisor_finalizer.

7. Đăng ký và đăng nhập

Tài khoản dùng tên đăng nhập và mật khẩu; sau khi đăng nhập, trình duyệt gửi JWT kèm mỗi request để lưu tin, giữ lịch sử chat và cá nhân hoá.

8. Lưu tin và cá nhân hoá

Mỗi hành vi được ghi thành một điểm; điểm đó quyết định tin nào đang được lưu và điều chỉnh thứ hạng kết quả Tư vấn AI theo sở thích của người dùng.

  • Trang chủ (mục 1) không cá nhân hoá; chỉ hybrid search trong Tư vấn AI dùng hồ sơ này.
  • Khách chưa đăng nhập vẫn được ghi hành vi theo session_id, nhưng không có hồ sơ và trạng thái tim mất sau khi tải lại trang.
